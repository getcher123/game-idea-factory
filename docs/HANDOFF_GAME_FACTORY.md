# Опциональная передача в Game Factory

Этот проект проектирует и утверждает **идею и дизайн**. После G9 выбранный продукт при отдельном поручении может передаваться в `getcher123/game-factory` или другую производственную систему.

## Пакет передачи

| Путь целевого проекта | Из каких данных собрать |
|---|---|
| `game.json` | Имя продукта, платформа, аудитория, циклы, версии, утверждённые параметры |
| `GDD.md` | Дизайн G9: правила, состояния, интерфейсы, стиль, уровни, экономика |
| `acceptance.json` | Измеримые требования, тесты, границы первой версии |
| `state.md` | Что действительно готово, блокеры, версионные артефакты, следующий маршрут |
| `assets/assets.csv` | Перечень ресурсов с назначением, источником, лицензией и текущим статусом |

**Важно:** экспорт этих данных не закрывает контрольные точки проекта-получателя. Его собственные согласования, QA, выпуск и SDK-проверки должны выполняться отдельно.

Перед передачей проверить фактическую структуру и версии файлов целевого репозитория. Никакого предположения, что локальный Godot, удалённый рабочий стол, OpenRouter или генератор изображений уже доступны в новой сессии.

В handoff обязательно включить отвергнутые механики и причины отказа, результаты реальных тестов (включая `not_run`), действующий baseline, пользовательские решения с источниками и список открытых вопросов.
