## Текущее решение

| ID | Концепт | Осмысленный выбор | Главный риск |
|---|---|---|---|
| **C1** | Обвал как лебёдка | Какой противовес даст достаточную массу и свободный ход для подъёма груза | Условность подъёмника, техническая устойчивость и малая глубина |
| **C2** | Передай скобу | Какую балку удерживать единственной переносимой скобой; безопасная последовательность в образце A→B→A | Непонятный запрет полного снятия и стратегия «всегда переключайся» |
| **C3** | Один ловитель | Кого спасти первым, чтобы обвал не отрезал путь к следующему грузу | Очевидный порядок и рутинная доставка к доку |

**Рекомендация автора — C3 по проверяемости.** Один снос одновременно спасает и меняет доступность маршрута. Это не установленная оригинальность, удовольствие или преимущество спроса. C1 интереснее для проверки эффекта «падение поднимает груз», C2 — для проверки отказа от прежней опоры.

**Ответ для выбора: C1, C2 или C3**, либо конкретные изменения/пересборка/пауза. Клики сравнительной схемы — только просмотр; настоящее решение регистрируется из сообщения пользователя по SHA предъявленной версии.

## Что исправило независимое ревью

В v1 C2 содержала ошибки масштаба/длины балки и источника движения, а полное снятие скобы давало неразобранную альтернативу переносу. В v2 скоба стала только переносимой, желоб и лишняя вводная волна удалены, геометрия согласована. Повторное ревью нашло препятствие на длинной дуге: балка раньше груза упиралась в удержанную опору. В v3 использована короткая верхняя дуга и ранний контакт с грузом; весь путь проверен на геометрические пересечения. Динамику и качество управления это не доказывает.

На G2 независимые проверки добровольные: маршрут не требует обязательных линз. Два разных агента не участвовали в авторстве G2. Финальные отзывы PASS не означают выбора концепта или успешного теста с игроками. Открытых critical/major в актуальных отзывах нет; гипотезы глубины, понимания и спроса остаются открытыми.

## Восстановление и продолжение

Актуальная приватная точка восстановления: **`game-idea-factory-pilot-20261111-01-g2-v3.zip`**. В ней весь run: фактические решения G0/G1, версии G1/G2, отзывы, источники, карточки и snapshots. Публичная проекция не восстанавливает полный SHA и историю. Старые архивы остаются историческими.

При отсутствии run восстановить актуальный архив в корень репозитория, затем выполнить:

```bash
python3 tools/pipeline.py status --run pilot-20261111-01
python3 tools/pipeline.py audit --run pilot-20261111-01
```

Не выполнять повторный `init` и не реконструировать согласие из публичного обзора. После реального выбора C1/C2/C3 зарегистрировать его для G2 v3. **Пилот ограничен G2**: такое решение завершит текущий run. A0/G3 и полный дизайн G9 относятся к отдельно согласованному продолжению; общий шаблон G2 не расширяет эту границу.
