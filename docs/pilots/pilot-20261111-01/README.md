Если `runs/pilot-20261111-01/` отсутствует, сначала восстановить архив в корень репозитория. После восстановления:

```bash
python3 tools/pipeline.py status --run pilot-20261111-01
python3 tools/pipeline.py audit --run pilot-20261111-01
```
