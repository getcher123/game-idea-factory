## Память и продолжение

Это очищенная публичная проекция. Полный run с реальным решением, исходными scouting-записями, обеими версиями G1 и snapshots находится вне Git. Актуальная точка восстановления: **`game-idea-factory-pilot-20261111-01-g1-v2.zip`**. Публичные файлы сами по себе не восстанавливают историю и полный SHA.

Если run отсутствует, восстановить архив в корень репозитория, затем выполнить:

```bash
python3 tools/pipeline.py status --run pilot-20261111-01
python3 tools/pipeline.py audit --run pilot-20261111-01
```

Не повторять `init`. Не реконструировать пользовательское согласие из этого обзора. После настоящего выбора T1/T2/T3 зарегистрировать ответ по SHA G1 v2 и перейти к трём концептам G2. После их предъявления требуется отдельное решение. A0, G3 и полный дизайн G9 не выполнены и не входят в завершённый объём этого пилота.
