# План проверки гипотезы · G2 / G5 / G10

План зафиксировать **до** наблюдений. Один эксперимент отвечает на один главный вопрос; не меняй метрику после просмотра результата без явной пометки о последующем анализе.

## Дизайн исследования

| Обязательное поле | Что зафиксировать |
|---|---|
| Run, gate, experiment_id, версия | На какой утверждённый gate, дизайн и версию ссылается эксперимент? |
| Цель и одна главная гипотеза | Проверяемое утверждение о поведении, а не «игра должна понравиться» |
| Альтернативные объяснения | Что ещё могло дать тот же эффект? |
| Варианты и контроль | G2: равное обещание; G5: сохранённая A0 vs одна мутация; G10: определённая сборка и когорта |
| Материалы и доступ | Конкретный путь playable, картинки, builds, сценарии; статус каждого до старта |
| Аудитория и способ набора | Возрастная группа, страна/язык, устройство, канал, органический/платный/`unknown`; кто проводит |
| Минимальная пригодная выборка | Сколько людей реально планируется и какой вывод при таком размере **недопустим** |
| Первичная метрика | Числитель, знаменатель, окно, единица, критерий события, способ регистрации |
| Дополнительные наблюдения | Ошибка понимания, причина остановки, повтор, эмоция, качество видео, комментарий |
| Порог решения / отказа | Заранее заявленное условие продолжить, исправить, откатить, остановить |
| Порядок показа | Слепое сравнение при возможности, рандомизация/контрбалансировка, паузы, одинаковые инструкции |
| Риски смещения | Знакомые, усталость, авторские подсказки, устройства, платное продвижение, разные уровни сложности |
| Приватность и права | Согласие на запись, минимум персональных данных, место хранения, ограничения по возрасту |
| Начало/конец и stop rules | Даты измерения; условия остановки по времени, бюджету и серьёзным дефектам |
| Статус | `planned` до начала; `not_run` если наблюдения отсутствуют; почему |

## Особые критерии по этапу

- **G2 — понимание и привлекательность:** сможет ли человек без обучения описать цель и ожидаемое последствие? Добровольный запуск демо измеряется отдельно от просмотров ролика.
- **G5 — удовольствие от ядра:** сравни сопоставимые игровые фрагменты, добровольный повтор, осмысленный выбор, причины раздражения; отдельно сообщи о любом изменении кроме одного правила. Допустимое решение — вернуть A0.
- **G10 — внешний тест:** заранее определи install/start, активность, первую полноценную сессию, D1/D7 по дате когорты и часовому поясу, отказы, crashes, атрибутированные приглашения, монетизацию при наличии. D7 закрывается только после полного окна; если нет трафика, не обещай статистическую уверенность.

## Как будет принято решение

Укажи, кто собирает данные, кто анализирует, что могут проверить независимые агенты, что требует человеческой аудитории. План и результаты хранятся отдельно. Не выдавай синтетику, самопрогон ИИ, запуск без людей или просмотры за реальные ответы игроков.
