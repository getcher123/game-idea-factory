# Результат эксперимента · факты отдельно от вывода

**Run / gate / experiment_id / исследователь / дата:** заполнить по факту.
**План до наблюдения:** неизменяемая версия [`experiment-plan.md`](experiment-plan.md), ID гипотезы, пути к сборкам/демонстрациям.
**Состояние:** `not_run` до реального проведения; после — указать наблюдаемый статус, срок и ограничения. Не ставь пустой эксперимент в статус `completed`.

## Фактически выполнено

| Поле | Доказательство |
|---|---|
| Даты начала и завершения окна | Таймзона, полнота окна; отдельно будущие периоды наблюдения |
| Фактические варианты | Воспроизводимые пути и версии A0/A1/B1/C1 или другой сравнимый материал |
| Рекрутинг | Способ получения участников, сколько приглашено/начало/завершило; реальный канал |
| Протокол | Что показано, порядок, одинаковые/разные условия, сбои |
| Сырые данные | Ссылки на обезличенные логи и наблюдения; кто и когда сделал запись |
| Качественные реакции | Дословные **реально записанные** ответы и заметки с обезличенными ID; ничего не реконструировать |
| Известные искажения | Подсказки интервьюера, неравный порядок, оборудование, краш, техническая ошибка |
| Недоступные измерения | `unknown`/`not_run`, почему метрика отсутствует |

## Отчёт по заранее заданным метрикам

Для каждой метрики заполни: **название → версия → числитель/знаменатель → единица → окно → значение → источник → ограничение → связь с гипотезой**. Если значений нет, впиши `not_run` и причину вместо процента. Отдельно покажи исходы по условиям, а не только среднее.

Дополнительный анализ после просмотра результата помечай как **post hoc** и объясняй, почему он не является подтверждением первоначального критерия.

## Суждение и решение

1. **Наблюдения:** без интерпретации — что участники делали и что в логах.
2. **Выводы:** какие из заявленных гипотез поддержаны, опровергнуты или остались неизвестны; границы обобщения.
3. **Причины ухода:** какие препятствия можно воспроизвести и что пока догадка.
4. **Решение по версии:** сохранить A0 / выбрать один вариант / исправить и повторить / остановить. Обоснуй порогом из плана и стоимостью изменения.
5. **Следующий минимальный тест:** что уменьшит оставшуюся неопределённость.
6. **Независимое ревью:** для G5 — `experiment_design` и `game_design` по одному зафиксированному SHA; замечания и повторные версии сохранить.

Мнение агента о «fun» может быть полезной гипотезой, но не подменяет наблюдаемое самостоятельное повторение человеком. Большой охват ролика не доказывает высокий D1/D7 или эффективное приглашение.
