# G0 · Рамка следующего игрового эксперимента

**Прогон / версия / автор / дата:** заполнить реальными значениями после `init`.
**Источник пользовательского запроса:** ссылка на сообщение и краткая точная цитата.
**Статус:** черновик до утверждения пользователем.

## Цель и границы

| Вопрос | Допустимые альтернативы и последствия выбора | Текущее знание / ограничение |
|---|---|---|
| Для кого и на каком языке игра? | География, контекст использования, доступность аудитории для тестов | Указать подтверждённое пользователем / `unknown` |
| Где запускается? | Браузер, мобильная система, платформа сообщества и т. п.; различия сборки, ввода, публикации | Не выдавать доступность платформы за проверенную без факта |
| Какая сессия и ввод? | Продолжительность, одна рука/две, мышь, сенсор, клавиатура, обучение | Как проверить удобство? |
| Какую эмоцию хотим проверить? | Удивление, напряжение, мастерство, комедийный провал, соперничество | Как она станет видна в действии? |
| Откуда первый игрок? | Short-form, друзья, сообщества, каталог игр, рекламу отличать от органики | Предполагаемый канал, доступ и стоимость |
| Почему кто-то вернётся/поделится? | Результат для сравнения, челлендж, новая задача, рекорд | Пока гипотеза, не обещание вирусности |
| Экономика и этические границы? | Бесплатно/реклама/покупка/не тестировать монетизацию; возраст, сбор данных | Допустимый метод, что запрещено |
| Срок, ресурсы, права? | Время до A0 и G2, устройства, бюджет, музыка/бренды/IP | Реальные доступные инструменты |

## Сравнимые варианты рамки

Для каждого **реально предлагаемого** варианта дай уникальный ID и одинаковые поля. Создавай столько, сколько нужно для осмысленного выбора, обычно 2–3.

| Поле каждого варианта | Что обязательно вписать |
|---|---|
| ID и название | Краткий неизменный ID для `options` manifest |
| Целевая аудитория / платформа | Конкретный, проверяемый контекст |
| Сессия / способ ввода | Как происходит первая минута |
| Эмоция / социальный повод | Наблюдаемое действие, которое можно проверить |
| Канал / экономика | Исходная гипотеза и риск |
| Оценка усилий / главный компромисс | Что ускорится, что станет труднее |
| Самый дешёвый тест G1–G2 | Что можно выяснить без большой разработки |

## Решение и последствия

- **Сравнение вариантов:** почему отличается поведение игрока, себестоимость проверки и шанс найти сигнал.
- **Рекомендация агента:** один ID и критерии, по которым он выбран; допущения выделить отдельно.
- **Неизвестное:** какие факты нужно выяснить в G1, что невозможно решить сейчас.
- **Неподлежащие изменению без возврата на G0 ограничения:** заполнить после реального решения.
- **Вопрос пользователю:** выбрать ID / указать поправку / вернуться / отложить / остановить.
- **После выбора:** G1 ищет реальные сигналы строго в утверждённых границах; новая игра пока не выбрана.

Запись фактического решения и SHA делает оркестратор по [`docs/APPROVALS.md`](../docs/APPROVALS.md), а не автор этого черновика.
