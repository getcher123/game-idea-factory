# Прогоны

Каждый рабочий прогон создаётся `python3 tools/pipeline.py init --run <id>` в `runs/<id>/`.

Файлы:

- `run.json` — машинный источник истины о стадии, предложениях, ревью и решениях.
- `evidence.jsonl` — независимые исходные свидетельства и оценки.
- `signals.jsonl` — нормализованные наблюдения со ссылками на свидетельства.
- `clusters.json` — группировка наблюдений/перепостов.
- `opportunities.json` — три направления G1 после исследования.
- `artifacts/` — карточки, записи игрового прототипа, игровые версии, тесты, полный дизайн.
- `reviews/` — самостоятельные отчёты субагентов с линзами и заключениями.
- `decisions/` — запись фактического ответа пользователя, когда она получена.
- `snapshots/` — сохранённые версии пакетов и отзывов; аудит проверяет их даже после возврата.

`runs/*` исключён из Git по умолчанию, чтобы не публиковать неочищенные данные тестеров или материалы исследования. При желании сделать публичный handoff готовят отдельный проверенный пакет без секретов и персональных данных.

Не используйте фиктивные данные из тестов как реальные наблюдения. Любой `run.json` должен принадлежать только одному прогону. `state.md` в корне — обзор, а не замена `run.json`.
